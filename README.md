# AP Calculus BC

Course notes and animated lesson slides for AP Calculus BC at Carmel Catholic High School,
based on Hass et al., *Thomas' Calculus: Early Transcendentals*, 15th ed. (Global ed., 2024).

## Authorship

- **Notes:** written by Conner Glover from the 15th edition textbook.
- **Slides:** generated by Claude from the textbook PDF and Conner's notes.

## Contents

| Path | What it is |
| --- | --- |
| `notes/notes.typ` | The course notes, written in [Typst](https://typst.app). One heading per chapter, section and subsection of the textbook. |
| `notes/template.typ` | Shared notes styling: cover, contents, running heads, numbered theorem/definition/example boxes, themes. |
| `compiled/notes.pdf` | The compiled notes. |
| `slides/` | Animated lessons, one per section, built with [manim](https://www.manim.community) and [manim-slides](https://github.com/jeertmans/manim-slides). See [`slides/README.md`](slides/README.md). |
| `cut_content.txt` | Textbook sections, chapters and subsections left out of the notes, and why (mostly content the AP exam doesn't test). |
| `e-textbook.pdf` | The source textbook. |

## Building the notes

Requires [Typst](https://typst.app). The `cetz` and `cetz-plot` packages download automatically on first compile.

```sh
typst compile notes/notes.typ compiled/notes.pdf
```

For a grayscale print version, pass `print: true` to `notes.with(...)` at the top of `notes.typ`.

### Writing conventions

Headings drive the numbering, contents and running heads:

```typst
= Chapter 3 -- Derivatives
== Section 3.2 -- The Derivative as a Function
=== Notation
```

Boxes available from the template:

- Numbered: `#theorem`, `#definition`, `#example`, `#formula` (label with `<name>`, cite with `@name`)
- Unnumbered: `#note`, `#warning`, `#proof`, `#solution`

## Viewing the slides

No install needed: open `slides/section_1_1.html` or `slides/section_1_2.html` in a browser.
Arrow keys or space step through each example; `F` goes fullscreen. Each HTML file needs its
`*_assets/` folder next to it.

To render, present or edit the slides, see [`slides/README.md`](slides/README.md).
